# trmnl-otd

Generated artifacts for the **On This Day — Ten Seconds Before** TRMNL plugin:
a daily woodcut of the moment ten seconds before history happened. Date and
location shown; the event is a mystery to guess.

Everything here is written by an automated daily job in the (private) source
repo. The gallery of every image lives on this repo's GitHub Pages site.

- `today.json` — polled by TRMNL (contract: schema 1)
- `images/YYYY/MM-DD.png` — the daily woodcuts
- `archive.json` / `used-events.json` — history + no-repeat memory
- `index.html`, `<year>.html` — the gallery (answers reveal next-day)
